# Scenario 01 export contracts

This directory mirrors the Wretched Demesne scenario layout.

`web-presentation.json` is the DIRPS Scenario 01 Web presentation contract introduced by issue #190 PX-A. It supplies player-facing phrasing and fiction for runtime-selected encounters and actions. It does **not** define action availability, progression, resolution, character balance, or replay semantics.

Target contracts may select presentation/representation, but they must not define RPG rules, character balance, progression, or replay semantics.
